## Описание

Данный репозиторий посвящён работе с билдом **'uCore build' 375, May 10 2006** - самым ранним опубликованным билдом игры Metro 2033.

Билд демонстрирует:
- Упор на **закрытые пространства**
- Продвинутое для своего времени **динамическое освещение**
- **Реалистичные тени** от всех объектов
